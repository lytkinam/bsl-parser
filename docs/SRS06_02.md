# SRS 06.02: MCP-сервер для SDQL

## 1. Назначение

Документ описывает реализацию MCP-сервера (Model Context Protocol), который предоставляет AI-агентам доступ к функциональности SDQL через стандартный протокол MCP. **Java-модули SDQL не изменяются** — MCP-сервер использует только публичный API, описанный в SRS 06.01.

**Принцип разделения:**
- SRS 06.01 — Java-ядро (контракт, модели, конвейер)
- SRS 06.02 — MCP-адаптер (HTTP API, JSON-RPC, трансляция запросов)

## 4. Точка входа

### 4.1 Класс `SdqlMcpServer`

```java
package com.github._1c_syntax.bsl.parser.sdql.mcp;

public class SdqlMcpServer {

    public static void main(String[] args) {
        // Парсинг аргументов:
        // --port=8080
        // --artifacts-dir=/var/sdql/artifacts
        // --temp-dir=/var/sdql/tmp
        // --log-level=INFO

        // Создание компонентов
        ModelRepository repository = new FileSystemModelRepository(artifactsDir);
        SdqlPipeline pipeline = new SdqlPipelineImpl(repository);
        NodeResolver nodeResolver = new NodeResolverImpl();
        QueryRestorer queryRestorer = new QueryRestorerImpl();
        ArtifactStore artifactStore = new ArtifactStore(tempDir);

        // Создание HTTP-сервера
        McpHttpServer server = new McpHttpServer(port,
            new McpRequestHandler(pipeline, nodeResolver, queryRestorer, artifactStore));

        server.start();
    }
}
```

### 4.2 Аргументы командной строки

| Аргумент | Описание | По умолчанию |
|----------|----------|--------------|
| `--port` | Порт HTTP-сервера | `8080` |
| `--artifacts-dir` | Директория для постоянных артефактов | `./artifacts` |
| `--temp-dir` | Директория для временных файлов (Online) | `./tmp` |
| `--log-level` | Уровень логирования | `INFO` |
| `--mode` | Режим: `mcp` или `cli` | `mcp` |

```json

    "arguments": {

      "nodeId": 86,
      "aliases": ["Взносы", "ПенсионныйСчет"],

  }
}
```

```json
{
  "jsonrpc": "2.0",

  "result": {
```

## 6. Реализация методов MCP

### 6.1 Общая логика обработки

```java
public class McpRequestHandler {

    public McpResponse handle(McpRequest request) {
        String toolName = request.getParams().getName();
        JsonNode args = request.getParams().getArguments();

        try {
            return switch (toolName) {
                case "analyze_sql_package" -> handleAnalyze(args);
                case "get_sdbl_model" -> handleGetSdblModel(args);
                case "get_line_pars_model" -> handleGetLineParsModel(args);
                case "get_full_pars_model" -> handleGetFullParsModel(args);
                case "get_hierarchy" -> handleGetHierarchy(args);
                case "get_field_lineage" -> handleGetFieldLineage(args);
                case "get_full_field_lineage" -> handleGetFullFieldLineage(args);
                case "get_restored_query" -> handleGetRestoredQuery(args);
                case "get_node_info" -> handleGetNodeInfo(args);
                case "list_nodes" -> handleListNodes(args);
                case "get_verification_report" -> handleGetVerificationReport(args);
                default -> errorResponse("UNKNOWN_TOOL", "Unknown tool: " + toolName);
            };
        } catch (SdqlApiException e) {
            return errorResponse(e.getCode(), e.getMessage());
        } catch (Exception e) {
            return errorResponse("INTERNAL_ERROR", e.getMessage());
        }
    }
}
```

### 6.2 Режим Online/Offline

```java
private PipelineContext resolveContext(JsonNode args) {
    String sqlText = getString(args, "sqlText");
    String baseName = getString(args, "baseName");
    boolean detailed = getBoolean(args, "detailed", false);

    if (sqlText != null) {
        // Online mode
        String generatedBaseName = baseName != null ? baseName : generateBaseName();
        Path tempDir = artifactStore.createTempDir(generatedBaseName);
        PipelineResult result = pipeline.analyze(sqlText, tempDir, generatedBaseName, detailed);
        return new PipelineContext(result.getBaseName(), tempDir, true);
    } else if (baseName != null) {
        // Offline mode
        Path artifactsDir = repository.getBasePath(baseName);
        if (!repository.exists(baseName)) {
            throw new SdqlApiException("ARTIFACT_NOT_FOUND", "Artifacts not found: " + baseName);
        }
        return new PipelineContext(baseName, artifactsDir, false);
    } else {
        throw new SdqlApiException("MISSING_INPUT", "Either sqlText or baseName must be provided");
    }
}
```

### 6.3 Разрешение узла (nodeId / nodeName)

```java
private FullParsNode resolveNode(FullParsModel model, JsonNode args) {
    Integer nodeId = getInt(args, "nodeId");
    String nodeName = getString(args, "nodeName");

    if (nodeId != null) {
        return nodeResolver.resolveById(model, nodeId);
    } else if (nodeName != null) {
        return nodeResolver.resolveByName(model, nodeName);
    } else {
        throw new SdqlApiException("MISSING_NODE", "Either nodeId or nodeName must be provided");
    }
}
```

### 6.4 Реализация `get_full_field_lineage`

```java
private McpResponse handleGetFullFieldLineage(JsonNode args) throws Exception {
    PipelineContext ctx = resolveContext(args);
    FullParsModel model = repository.loadFullParsModel(ctx.getBaseName());
    FullParsNode node = resolveNode(model, args);
    List<String> aliases = getStringList(args, "aliases");
    boolean includeRelated = getBoolean(args, "includeRelated", false);

    // Используем Java API
    FullFieldLineageBuilder builder = new FullFieldLineageBuilder();
    List<FullParsNode> fflNodes = builder.build(model, node.getId(), aliases);

    // Очистка временных файлов (Online)
    if (ctx.isOnline()) {
        artifactStore.cleanup(ctx.getBaseName());
    }

    return successResponse(Map.of(
        "baseName", ctx.getBaseName(),
        "nodeId", node.getId(),
        "nodeName", node.getName(),
        "aliases", aliases,
        "fflNodes", fflNodes
    ));
}
```

### 6.5 Реализация `get_restored_query`

```java
private McpResponse handleGetRestoredQuery(JsonNode args) throws Exception {
    PipelineContext ctx = resolveContext(args);
    FullParsModel model = repository.loadFullParsModel(ctx.getBaseName());
    FullParsNode node = resolveNode(model, args);
    List<String> aliases = getStringList(args, "aliases");
    String format = getString(args, "format", "sql");

    // Построение FFL
    FullFieldLineageBuilder builder = new FullFieldLineageBuilder();
    List<FullParsNode> fflNodes = builder.build(model, node.getId(), aliases);

    if ("json".equals(format)) {
        // Возвращаем RestoredQueryNode
        QueryNodeBuilder nodeBuilder = new QueryNodeBuilder(
            fflNodes.stream().collect(Collectors.toMap(FullParsNode::getId, n -> n)),
            model.getNodes().stream().collect(Collectors.toMap(FullParsNode::getId, n -> n))
        );
        RestoredQueryNode restored = nodeBuilder.build(fflNodes.get(0));
        return successResponse(Map.of("restoredQueryNode", restored));
    } else {
        // Возвращаем SQL
        String sql = queryRestorer.restore(fflNodes,
            model.getNodes().stream().collect(Collectors.toMap(FullParsNode::getId, n -> n)));
        return successResponse(Map.of(
            "baseName", ctx.getBaseName(),
            "nodeId", node.getId(),
            "nodeName", node.getName(),
            "aliases", aliases,
            "sql", sql
        ));
    }
}
```

## 7. Коды ошибок MCP

| Код MCP | Код Java | HTTP | Описание |
|---------|----------|------|----------|
| `-32602` | `MISSING_INPUT` | 400 | Не указан `sqlText` или `baseName` |
| `-32602` | `MISSING_NODE` | 400 | Не указан `nodeId` или `nodeName` |
| `-32602` | `NODE_NOT_FOUND` | 404 | Узел не найден |
| `-32602` | `ALIAS_NOT_FOUND` | 404 | Alias не найден в узле |
| `-32602` | `ARTIFACT_NOT_FOUND` | 404 | Артефакты не найдены (Offline) |
| `-32603` | `PIPELINE_ERROR` | 500 | Ошибка в конвейере |
| `-32603` | `INTERNAL_ERROR` | 500 | Внутренняя ошибка |

## 9. Зависимости от Java-модулей

MCP-сервер использует только публичные классы из `sdql.api`:

| Java-модуль | Использование |
|-------------|---------------|
| `SdqlPipeline` | Запуск конвейера |
| `PipelineResult` | Получение результата |
| `ModelRepository` | Загрузка/сохранение моделей |
| `NodeResolver` | Разрешение nodeName → nodeId |
| `QueryRestorer` | Восстановление SQL |
| `SdqlApiException` | Обработка ошибок |

**MCP-сервер НЕ использует напрямую:**
- `SdqlCli` (только через `SdqlPipeline`)
- `LineParsModelBuilder` (только через `SdqlPipeline`)
- `FullParsModelBuilder` (только через `SdqlPipeline`)
- `QueryReconstructor` (только через `QueryRestorer`)
