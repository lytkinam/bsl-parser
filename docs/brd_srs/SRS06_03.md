# SRS 06.03: Docker-интеграция и автозапуск MCP-сервера SDQL

## 1. Назначение

Документ описывает интеграцию MCP-сервера SDQL (реализованного в SRS 06.02) в Docker-инфраструктуру AI-стека, настройку автозапуска через systemd и обновление скилла `ubuntu-admin`.

**Принцип:** MCP-сервер SDQL работает как Docker-контейнер внутри существующей сети `ai-network`, получает запросы по HTTP JSON-RPC 2.0 и использует fat-jar (shadowJar) для автономной работы.

## 2. Текущее состояние

- **MCP-сервер SDQL**: реализован в `com.github._1c_syntax.bsl.parser.sdql.mcp.SdqlMcpServer`
- **Порт по умолчанию в коде**: 8080 (в `SdqlMcpServer.java`)
- **Утверждённый порт для Docker**: 5372
- **Jar**: обычный jar (~577KB), не содержит зависимости
- **AI-стек**: работает (Redmine 3000, OpenViking 1933, LiteLLM 4000, Qdrant 6333, MCP Qdrant 8000)
- **Сеть**: `ai-network` (bridge, external) существует
- **systemd ai-stack.service**: не создан
- **Скилл ubuntu-admin**: `~/.config/agents/skills/ubuntu-admin/` — нет раздела SDQL MCP

## 3. Целевое состояние

### 3.1 Shadow JAR

Добавить плагин `com.github.johnrengelman.shadow` версии `8.1.1` в `build.gradle.kts`:

```kotlin
plugins {
    // ... existing plugins ...
    id("com.github.johnrengelman.shadow") version "8.1.1"
}

tasks.shadowJar {
    archiveClassifier.set("all")
    mergeServiceFiles()
    manifest {
        attributes["Main-Class"] = "com.github._1c_syntax.bsl.parser.sdql.mcp.SdqlMcpServer"
    }
}
```

### 3.2 Dockerfile

Создать `Dockerfile` в корне проекта:

```dockerfile
FROM eclipse-temurin:17-jre-alpine
WORKDIR /app
COPY build/libs/*-all.jar app.jar
EXPOSE 5372
ENTRYPOINT ["java", "-jar", "app.jar"]
CMD ["--port=5372", "--artifacts-dir=/app/artifacts", "--temp-dir=/tmp"]
```

### 3.3 Docker Compose

Создать `~/sdql-mcp/docker-compose.yml`:

```yaml
services:
  sdql-mcp:
    build:
      context: /tmp/bsl-parser
      dockerfile: Dockerfile
    container_name: sdql-mcp
    ports:
      - "5372:5372"
    volumes:
      - ./artifacts:/app/artifacts
    networks:
      - ai-network
    restart: unless-stopped

networks:
  ai-network:
    external: true
```

### 3.4 Скрипт запуска AI-стека

Создать/обновить `~/.config/agents/skills/ubuntu-admin/scripts/ai-start-all-services.sh`:

```bash
#!/bin/bash
# Запуск AI-стека в правильном порядке

set -e

STACK_HOME="${STACK_HOME:-$HOME/ai-stack}"

start_compose() {
    local dir="$1"
    local name="$2"
    if [ -f "$dir/docker-compose.yml" ]; then
        echo "Starting $name..."
        docker compose -f "$dir/docker-compose.yml" up -d
    else
        echo "WARNING: $dir/docker-compose.yml not found"
    fi
}

# 1. Ollama (systemd)
sudo systemctl start ollama || true

# 2. LiteLLM
start_compose "$STACK_HOME/litellm" "LiteLLM Proxy"

# 3. OpenViking
start_compose "$STACK_HOME/openviking" "OpenViking"

# 4. Redmine + Qdrant
start_compose "$STACK_HOME/redmine" "Redmine"

# 5. SDQL MCP
start_compose "$HOME/sdql-mcp" "SDQL MCP"

echo "AI stack started."
```

### 3.5 Скрипт проверки

Создать/обновить `~/.config/agents/skills/ubuntu-admin/scripts/ai-system-check.sh`:

```bash
#!/bin/bash
# Проверка здоровья AI-стека

pass() { echo "[PASS] $1"; }
warn() { echo "[WARN] $1"; }

# Docker
docker info >/dev/null 2>&1 && pass "Docker is running" || warn "Docker is NOT running"

# Ollama
if pgrep -x ollama >/dev/null; then
    pass "Ollama is running"
else
    warn "Ollama is NOT running"
fi

# LiteLLM
if curl -s --max-time 5 http://localhost:4000/health >/dev/null 2>&1; then
    pass "LiteLLM is responding on :4000"
else
    warn "LiteLLM is NOT responding on :4000"
fi

# OpenViking
if curl -s --max-time 5 http://localhost:1933/health >/dev/null 2>&1; then
    pass "OpenViking is responding on :1933"
else
    warn "OpenViking is NOT responding on :1933"
fi

# Redmine
if curl -s --max-time 5 http://localhost:3000 >/dev/null 2>&1; then
    pass "Redmine is responding on :3000"
else
    warn "Redmine is NOT responding on :3000"
fi

# Qdrant
if curl -s --max-time 5 http://localhost:6333 >/dev/null 2>&1; then
    pass "Qdrant is responding on :6333"
else
    warn "Qdrant is NOT responding on :6333"
fi

# SDQL MCP
if docker ps --format '{{.Names}}' | grep -q '^sdql-mcp$'; then
    pass "Container 'sdql-mcp' is running"
else
    warn "Container 'sdql-mcp' is NOT running"
fi

if curl -s --max-time 5 http://localhost:5372/health >/dev/null 2>&1; then
    pass "SDQL MCP is responding on :5372"
else
    warn "SDQL MCP is NOT responding on :5372"
fi
```

### 3.6 Systemd unit

Создать `/etc/systemd/system/ai-stack.service`:

```ini
[Unit]
Description=AI Stack Auto-Start (Ollama, Docker, LiteLLM, OpenViking, Redmine, SDQL MCP)
After=docker.service ollama.service network.target
Wants=docker.service ollama.service

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/home/user/.config/agents/skills/ubuntu-admin/scripts/ai-start-all-services.sh --auto
StandardOutput=append:/var/log/ai-stack.log
StandardError=append:/var/log/ai-stack.log

[Install]
WantedBy=multi-user.target
```
